# Data Directory

This directory is intended to hold the dataset for the Credit Risk Modelling project.

**Do NOT commit large CSV files to the repository.**

## How to get the data
1. Go to the [Home Credit Default Risk Kaggle Competition](https://www.kaggle.com/datasets/megancrenshaw/home-credit-default-risk).
2. Download `application_train.csv`.
3. Place `application_train.csv` directly in the root of the project (or inside this `data/` folder and adjust paths accordingly). The scripts expect it in the root by default (`./application_train.csv`).
